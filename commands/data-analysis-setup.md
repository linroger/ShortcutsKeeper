# Data Analysis Setup Command

**Command**: `/project:data-analysis-setup`

## Purpose
Initialize comprehensive data analysis environment with proper libraries, dataset exploration, and professional visualization framework.

## Workflow

Please set up a complete data analysis environment following these steps:

1. **Environment Setup**
   - Import all essential libraries (pandas, numpy, plotly, scipy, etc.)
   - Set up proper data visualization framework using Plotly (never matplotlib)
   - Configure notebook settings for professional output
   - Initialize any domain-specific libraries (QuantLib for finance, etc.)

2. **Dataset Analysis**
   - Load and inspect all provided datasets
   - Analyze data structure, types, and relationships between datasets
   - Identify missing values, outliers, and data quality issues
   - Generate comprehensive descriptive statistics
   - Create initial exploratory visualizations

3. **Data Validation Framework**
   - Implement data quality checks and validation rules
   - Set up automated data cleaning procedures
   - Create functions for handling missing data appropriately
   - Establish data integrity verification methods

4. **Visualization Standards**
   - Set up professional Plotly themes and color schemes
   - Create reusable plotting functions for common chart types
   - Implement interactive visualizations with hover data
   - Establish consistent styling for all charts and graphs

5. **Analysis Framework**
   - Create modular analysis functions for reusability
   - Set up proper error handling for data operations
   - Implement logging and progress tracking for long operations
   - Create template structures for different analysis types

6. **Documentation Setup**
   - Create markdown cells with clear section headers
   - Document all data sources and their characteristics
   - Add methodology explanations for analysis approaches
   - Set up template for executive summary and conclusions

**For Financial Analysis**: Include QuantLib setup, risk metrics calculations, and academic citation framework
**For Scientific Analysis**: Include statistical testing frameworks and hypothesis validation methods
**For Business Analysis**: Include KPI tracking and business metrics calculation functions

**Success Criteria**:
- All data loaded successfully with proper validation
- Professional visualization framework operational
- Comprehensive data profiling completed
- Analysis templates ready for implementation
- Documentation structure established
