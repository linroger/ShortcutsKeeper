# Multi-Agent Research Command

**Command**: `/project:multi-agent-research`

## Purpose
Deploy multiple specialized agents to conduct comprehensive research and analysis across different aspects of a complex project or topic.

## Arguments
**Usage**: `/project:multi-agent-research [RESEARCH_TOPIC]`

Where `[RESEARCH_TOPIC]` is the main subject to research (e.g., "Swift Charts implementation", "QuantLib bond pricing", "MLX voice synthesis")

## Workflow

Please coordinate a multi-agent research operation following this structure:

1. **Research Task Decomposition**
   - Break down the research topic into 3-5 independent research areas
   - Identify specific expertise areas needed for each component
   - Define clear research objectives and deliverables for each agent
   - Establish success criteria for comprehensive coverage

2. **Agent Assignment and Coordination**
   - Deploy specialized agents for each research area:
     - **Technical Implementation Agent**: Focus on code examples, APIs, and integration patterns
     - **Architecture Analysis Agent**: Examine system design, patterns, and best practices
     - **Performance & Optimization Agent**: Research efficiency, benchmarks, and optimization techniques
     - **Documentation & Standards Agent**: Gather official documentation, guidelines, and standards
     - **Comparative Analysis Agent**: Research alternatives, trade-offs, and competitive solutions

3. **Parallel Research Execution**
   - Use Task tool to run multiple agents simultaneously
   - Provide each agent with specific, focused research instructions
   - Include relevant context and constraints for each research area
   - Specify expected output format and level of detail

4. **Research Integration and Synthesis**
   - Collect and analyze outputs from all research agents
   - Identify common themes, conflicts, and complementary insights
   - Synthesize findings into comprehensive research summary
   - Highlight key actionable recommendations and implementation strategies

5. **Quality Control and Validation**
   - Cross-validate findings between different agents
   - Identify gaps or areas needing additional research
   - Verify accuracy of technical details and implementation approaches
   - Ensure comprehensive coverage of the research topic

6. **Deliverable Creation**
   - Create comprehensive research report with executive summary
   - Provide implementation roadmap based on research findings
   - Document key insights, recommendations, and next steps
   - Include relevant code examples, patterns, and best practices

**Research Output Structure**:
- **Executive Summary**: Key findings and recommendations
- **Technical Analysis**: Implementation details and code patterns
- **Architecture Insights**: Design patterns and system organization
- **Performance Considerations**: Optimization strategies and benchmarks
- **Implementation Roadmap**: Step-by-step action plan
- **Resource References**: Documentation, examples, and additional sources

**Success Criteria**:
- Comprehensive coverage of research topic from multiple perspectives
- Actionable recommendations with clear implementation paths
- Technical accuracy validated across multiple sources
- Clear prioritization of next steps and implementation strategy
- Professional documentation suitable for decision-making and implementation
